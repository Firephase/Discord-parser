Enter your Discord user token to get started

How to get your user token
  1. Open discord.com/app in your browser (logged in)
  2. Press F12 → Network tab
  3. Refresh the page or send any message
  4. Click any request to discord.com/api/…
  5. Find the Authorization request header → copy its value

⚠ This is a user token, NOT from the Developer Portal. Self-bots violate Discord ToS.
